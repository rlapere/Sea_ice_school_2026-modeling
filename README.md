# Saroma sea ice school 2026 - modeling tutorials
Here we elaborate and store the tutorials on modeling for the Saroma sea ice school 2026. Four different Jupyter notebooks are made available to the students, with a Binder laucher to run the notebooks (`launch` icon next to the file description).

Three different notebooks are included here:
- [beginners.ipynb](beginners.ipynb) is designed for students with less experience in coding and/or notebooks [![Binder](https://mybinder.org/badge_logo.svg)](https://mybinder.org/v2/gh/rlapere/Sea_ice_school_2026-modeling/HEAD?urlpath=%2Fdoc%2Ftree%2Fbeginners.ipynb)
- [general.ipynb](general.ipynb) contains basic examples and tips for climate data retrieval and plotting [![Binder](https://mybinder.org/badge_logo.svg)](https://mybinder.org/v2/gh/rlapere/Sea_ice_school_2026-modeling/HEAD?urlpath=%2Fdoc%2Ftree%2Fgeneral.ipynb)
- [statistical_analysis.ipynb](statistical_analysis.ipynb) contains examples of statistical analysis useful for climate data [![Binder](https://mybinder.org/badge_logo.svg)](https://mybinder.org/v2/gh/rlapere/Sea_ice_school_2026-modeling/HEAD?urlpath=%2Fdoc%2Ftree%2Fstatistical_analysis.ipynb)
- [challenges.ipynb](challenges.ipynb) contains a challenge to apply your knowledge and skill aqcuired in this modelling lab [![Binder](https://mybinder.org/badge_logo.svg)](https://mybinder.org/v2/gh/rlapere/Sea_ice_school_2026-modeling/HEAD?urlpath=%2Fdoc%2Ftree%2Fchallenges.ipynb)
